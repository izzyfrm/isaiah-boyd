Use it with your AI

The repo ships an AI-GUIDE.md that tells an assistant what to trust and how to work. Point yours at it.

  1. Pick a direction.
    Search the catalog above (or index.json) and choose one primary style per game.
  2. Open the entry folder.
    Each README has the look, a Roblox recipe, pictures and links.
  3. Check the API.
    official-docs/ is authoritative for class, property and enum names.
  4. Start from the cookbook, then test in Studio and report what was and wasn't tested.
Read AI-GUIDE.md and index.json in https://github.com/izzyfrm/roblox-ai. Pick one GUI style that fits my game, open its folder README, verify every class and property in official-docs/ before writing Luau, start from a matching cookbook script if one exists, and tell me exactly what you tested in Studio.

What to trust

Not everything here has the same evidence behind it. The labels are deliberate.

Authoritative: official-docs/ is Roblox's own documentation (CC BY 4.0).
Compile-checked: cookbook/ scripts were compiled in Roblox Studio and most were run against unparented instances. None were checked in a live game; visuals and audio were not judged.
Not tested: style descriptions, palettes and recipes outside the cookbook are synthesis from general knowledge and linked sources.
Not yours to reuse: preview pictures belong to their creators (itch.io listings). Use them as references and check licences before using any asset.
